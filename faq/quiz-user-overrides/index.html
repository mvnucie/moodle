How can I give an additional quiz attempt or more time to a student?

Back to Moodle FAQ

Use a user override when one student needs different quiz settings without changing the quiz for everyone else. An override can provide additional time, another attempt, different availability dates, or a different password.

Add a User Override

  1. Open the Quiz

    Open your Moodle course and select the quiz you need to adjust.

  2. Open Overrides

    On the quiz page, open the three-dot menu in the row of quiz navigation options and select Overrides.

  3. Select the Student

    Select Add user override. In the Override user field, search for and select the student.

  4. Set the Exception

    Change only the setting or settings that should be different for this student:

    • Open the quiz: Set a different date and time when the student may begin accessing the quiz.
    • Close the quiz: Set a later deadline or a different closing time.
    • Time limit: Enter the student's complete adjusted time limit.
    • Attempts allowed: Enter the total number of attempts the student may make.
    • Require password: Set a different quiz password for the student if needed.

    Important: Enter the student's new total allowance, not the amount being added. For a 60-minute quiz with time-and-a-half, enter 90 minutes. If a student originally had one attempt and should receive one additional attempt, set Attempts allowed to 2.

    The student's availability window must also be long enough to use the extended time. If necessary, set a later Close the quiz date and time in the override.

  5. Save the Override

    Select Save. If you need to create an override for another student, select Save and enter another override.

Important Details

Extended Time and Availability

Changing the Time limit does not reopen a quiz that has already closed. If the regular closing date has passed, also provide a later Close the quiz date in the student's override.

If Moodle warns that the override is inactive, check the quiz's Restrict access conditions. A separate date or other access restriction can still prevent the student from opening the quiz.

Additional Attempts

Increasing Attempts allowed preserves the student's previous attempt and permits another one. For example, changing the total from one attempt to two allows a second attempt without removing the first.

If the previous attempt should be removed instead, review the student's attempt in the quiz results and delete it only when appropriate. Deleting an attempt permanently removes its recorded responses and grade.

Review or Change an Override

Return to the quiz and select Overrides from the three-dot menu. From the Overrides page, you can edit, duplicate, or delete an override.

Before leaving the page, verify the student's name, time limit, availability dates, and total number of attempts.
