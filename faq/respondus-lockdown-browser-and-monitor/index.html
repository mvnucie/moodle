How do I use Respondus LockDown Browser and Monitor for a Moodle quiz or exam?

Back to Moodle FAQ

Respondus LockDown Browser is a secure browser that prevents students from printing, copying, opening other websites, using other applications, or leaving a Moodle quiz until they submit it. Respondus Monitor adds automated webcam proctoring and records the student during the attempt.

Use LockDown Browser when students will take a Moodle quiz or exam on their own device and you want to restrict access to other digital resources. It is available without a limit at MVNU. Respondus Monitor is reserved for fully online courses because MVNU has a limited number of Monitor licenses. Contact the Center for Innovative Education to confirm license availability before you enable it. Residential students enrolled in an online course should take Monitor-required exams at the Test Center, as described below.

Choose the Right Tool

LockDown Browser

LockDown Browser is appropriate when you want students to take a quiz or exam in a restricted testing environment. It does not record students, their surroundings, or their webcam. You may use it for any course without requesting permission from CIE.

Respondus Monitor

Respondus Monitor requires LockDown Browser and then guides students through a webcam and environment check before the quiz begins. It records the attempt for the instructor to review afterward. Use it only for a fully online course after CIE confirms that a Monitor license is available.

Set Up the Quiz or Exam

Create and configure the Moodle quiz as you normally would, including its questions, availability dates, time limit, and grade settings. Then open the Respondus LockDown Browser Dashboard block from the toolbar on the right side of the course page. The Dashboard lists the quizzes available in the course and is where you apply Respondus settings.

  1. Locate the quiz in the Dashboard

    Find the quiz or exam you want to secure. Select the collapsible arrow beside its name, then select Settings.

  2. Require LockDown Browser

    Select Require LockDown Browser for this exam. Leave the proctoring setting at Don't require Respondus Monitor for this exam when you only need the restricted browser.

  3. Enable Monitor only when approved

    If CIE has confirmed Monitor availability for your fully online course, select Require Respondus Monitor (automated proctoring) for this exam. Choose the appropriate proctoring option for the assessment and review the student startup sequence that Respondus displays.

    Monitor requires a webcam, microphone, and broadband connection. If you enable a setting such as screen recording or a second camera, make sure students receive those requirements in advance.

  4. Save and confirm the setting

    Select Save + Close. Back on the Dashboard, confirm that LockDown Browser is required for the quiz. If you enabled Monitor, confirm that the Monitor column shows it as required.

Allow Test Center Use for Residential Students

For residential students who are enrolled in a fully online course, arrange for the Test Center to proctor Monitor-required exams. This lets the student use LockDown Browser without using a Respondus Monitor license.

  1. Open the Monitor advanced settings

    After selecting Require Respondus Monitor (automated proctoring) for this exam, select the plus sign beside Advanced Settings.

  2. Allow delivery in a proctored lab

    Select Allow this exam to additionally be delivered in a proctored lab (no webcam recording), then enter a password.

    Do not give this password to students. Send it only to the Test Center. A Test Center staff member will enter it when the student begins the exam.

Prepare Students Before the Exam

Tell students well before the first graded quiz or exam that they will need to use Respondus LockDown Browser. When students open a quiz or exam that requires it, Moodle provides options to Download LockDown Browser, Check your LockDown Browser Setup, or Launch LockDown Browser. They must install the MVNU version on the same computer they plan to use for the assessment.

Students do not install a separate Monitor application. When an exam requires Respondus Monitor, its webcam check and startup sequence run within LockDown Browser.

For a quiz or exam that requires Monitor, tell students to use a supported computer with a working webcam and microphone, a reliable broadband connection, and a quiet, well-lit location. Students should close other applications before launching LockDown Browser. Mobile phones cannot be used for either product.

Use a practice quiz: Create a short, low-stakes practice quiz that requires the same Respondus product as the graded quizzes or exams. For example, use LockDown Browser alone for a LockDown Browser course, or LockDown Browser with Monitor for a Monitor course. Give students multiple attempts and leave the practice quiz available throughout the course so they can test a different computer or network if needed.

Review Respondus Monitor Results

After a Monitor quiz or exam is completed, return to the Respondus LockDown Browser Dashboard. Use the quiz's context menu to open Class Results. Review the results and recordings as needed before making a decision about an individual attempt.

Monitor records and flags events for instructor review. A flag is not, by itself, proof of an academic-integrity violation. Consider the recording and relevant course context before following your usual academic-integrity process.
