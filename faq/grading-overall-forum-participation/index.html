How can I grade a student’s overall participation in a forum?

Back to Moodle FAQ

Use Whole forum grading to assign one grade for a student’s overall participation across posts and replies in a forum. Moodle gathers that student’s contributions in one grading interface, so you can assess their quality, engagement with classmates, and use of course concepts together. Ratings instead assign scores to individual posts and combine those scores into a grade.

Enable Whole Forum Grading

  1. Open the Forum Settings

    Open the forum from your course and select Settings in the toolbar at the top of the forum. Expand Whole forum grading.

  2. Set the Grade and Grading Method

    Under Grade, set Type to Point and enter the Maximum grade, such as 10 for a discussion worth 10 points. If your course uses a grading scale instead, choose Scale and select the appropriate scale.

    Choose one Grading method:

    • Simple direct grading: Enter one overall grade directly.
    • Grading guide: Enter a score up to the maximum for each criterion and add criterion-specific feedback. This allows flexible point values within each criterion.
    • Rubric: Select a predefined performance level for each criterion and add remarks where enabled. Each level has a fixed point value.

    For a graded discussion, criteria might include the quality of the initial response, engagement with classmates, and connections to course material. State your participation expectations in the forum instructions.

  3. Turn Off Ratings and Save

    Expand Ratings and set Aggregate type to No ratings. Then select Save and display.

    Use one grading approach per forum. Enabling both Whole forum grading and Ratings creates two separate gradebook items for the same forum, one for each approach. For one overall participation grade, enable whole forum grading and leave ratings off. If you choose to use ratings instead, leave the whole forum grade Type set to None.

  4. Prepare the Grading Guide or Rubric

    If you chose Grading guide or Rubric, open Advanced grading from the forum toolbar after saving. Define the form from scratch or reuse an available form. Add the criteria, descriptions, and points, review the student visibility and feedback options, and save the form as ready for use. A draft form isn't ready for grading.

    For a guide, define a maximum score for each criterion. For a rubric, define the performance levels and their point values. The forum’s Maximum grade controls the final grade recorded in the gradebook, so check that the form produces the scores you intend.

    See How do I use rubrics and grading guides in Moodle? for more details.

Grade Each Student’s Participation

  1. Open the Grading Interface

    Return to the forum and select Grade users above the discussion list. Check the name in the grading panel before entering a grade. Use Search users to find and select a particular student.

  2. Review the Student’s Contributions

    Read the student’s posts and replies shown in the main area. Select View discussion or View parent post when you need to see the surrounding conversation and evaluate how the contribution connects with other posts.

  3. Enter and Save the Overall Grade

    With Simple direct grading, enter the overall score in Grade. With a Grading guide, score each criterion and enter feedback. With a Rubric, select a level for each criterion and enter remarks where available.

    Under Notifications, choose whether to notify the student. Select Save to save the current student’s grade, or use the next-user arrow to save changes and proceed to the next student. The previous-user arrow also saves changes before moving to the previous student.

    Repeat for each student. Save your final grade before selecting Close grader.

How Students View Their Grade and Feedback

Once the grade is available to students, they can see the overall score in the course gradebook. To see the completed rubric or grading guide, including criterion scores and feedback, they need to open the forum itself and select View grades above the discussion list.

Forum → View grades

The normal gradebook User report doesn't display the detailed forum rubric or grading-guide feedback. Direct students to View grades inside the forum when you want them to review that feedback.

See How can students see feedback left in a rubric or grading guide? for more details.
