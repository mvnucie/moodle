How do I submit midterm or final grades?

Back to Moodle FAQ

Open the Moodle course whose grades you're submitting. The ILP Integration block sends each student's overall course grade to the Registrar's office, rather than individual assignment or activity grades.

Submit Your Grades

  1. Check your course grades

    Select Grades from the toolbar at the top of the course. Check that individual assignment and activity grades are accurate and that the gradebook calculation matches your syllabus.

    Confirm each student's overall course grade. For midterm reporting, it should reflect work through the reporting point. For final reporting, it should reflect the completed course. Resolve grading or calculation errors before continuing.

  2. Open ILP Integration

    Return to the main course page and find ILP Integration in the right-hand toolbar. If the toolbar is collapsed, use the expand control on the right edge of the page to reopen it. The toolbar stays collapsed until you reopen it, so the block may be out of view.

    Choose the link for the grades you're submitting:

    • ILP Integration → Midterm Grades
    • ILP Integration → Final Grades

  3. Populate the grade column

    Above the grade table, open the dropdown showing --Select the column to populate--. Choose Midterm 1 on the midterm page or Final Grade on the final page.

    This copies the letter grades from Current Grade into the selected submission column. Populating the column prepares the grades for review; it doesn't submit them.

  4. Review and adjust the grades

    Review every student's grade in Midterm 1 or Final Grade. Confirm that each value is the grade you intend to report, and edit individual values in that column if an adjustment is needed.

    If Current Grade is incorrect, return to the gradebook and correct the underlying grades or calculation. Then confirm that the submission column reflects the corrected grade.

  5. Submit and check the result

    Select Submit Grades at the bottom of the table. Read the result message and check whether all grades were submitted successfully.

If Some Grades Don't Go Through

If an error says that some grades weren't submitted, select Submit Grades again, then check the new result. It's safe to retry after an error, and another attempt may send through additional grades.

If repeated attempts leave the same grades unsubmitted, email those grades to MVNU.Registrar@mvnu.edu and copy cie@mvnu.edu. Include the course and section, the affected students and their grades, and the error message so the Registrar can record the grades and CIE can investigate the issue.
