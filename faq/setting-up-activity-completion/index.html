How do I set up Activity completion for an activity or resource?

Back to Moodle FAQ

Activity completion gives students a visible way to track what they have finished and lets Moodle record progress for each activity or resource. You can let students mark an item complete themselves or have Moodle mark it complete automatically when specific requirements are met.

Activity completion tracks progress, but it does not by itself hide later content. That is handled by Restrict access. A separate article will explain how to use Activity completion and Restrict access together to control progress through a course.

Choose a Completion Method

The best setting depends on what you want completion to mean for that item.

Let Students Mark the Item Complete

Choose Students can manually mark the activity as completed when completion is primarily a self-check. This can work well for a reading, an offline task, or another item Moodle cannot verify automatically.

A student can select Mark as done without completing any action that Moodle can confirm, so manual completion should not be used as proof that required work was submitted or graded.

Have Moodle Mark the Item Complete

Use Add requirements when Moodle should determine completion from recorded activity, such as viewing a resource, submitting an assignment, receiving a grade, completing quiz attempts, or contributing to a forum.

If you select more than one requirement, the student must meet all of them before Moodle marks the item complete.

Do Not Track Completion

Leave Activity completion set to None when the item does not need a completion status. Not every course item needs to be included in the student's progress checklist.

Configure Activity Completion

  1. Enable Completion Tracking for the Course

    From the main course page, select Settings. Scroll down and expand Completion tracking, set Enable completion tracking to Yes, and save the course settings.

    Activity completion settings will not appear within individual activities and resources unless completion tracking is enabled for the course.

  2. Open the Activity or Resource Settings

    Open the activity or resource and select Settings from the menu at the top of the page.

    For an item that does not have its own page, such as a Text and media area, turn Editing mode on and select Edit settings from the item's edit menu.

  3. Expand Completion Conditions

    Expand the Completion conditions section near the bottom of the settings page.

    If this section is not available, see Step 1 and confirm that completion tracking is enabled for the course.

  4. Select the Completion Method and Requirements

    Choose the method that matches the purpose of the item:

    • Leave None selected if completion should not be tracked.
    • Choose Students can manually mark the activity as completed for a student-controlled checklist.
    • Select Add requirements and choose one or more conditions for automatic completion.

    The automatic requirements shown will vary by activity type. Select only the conditions that represent meaningful completion of the item.

  5. Set a Timeline Reminder if Needed

    Use Set reminder in Timeline if an additional reminder would be helpful for this activity. This date appears in the student's Timeline in addition to any open, close, or due dates already configured for the activity.

    The Timeline reminder does not determine whether the item is complete, replace the activity's other dates, or prevent late access.

  6. Save the Settings

    Select Save and return to course. The activity or resource will now display its completion requirements and status to students.

Understand Common Automatic Requirements

Moodle displays only the completion requirements supported by that type of activity or resource.

View the Activity

View the activity marks the item complete when the student opens it. This is often the only automatic option for a Page, File, Folder, or URL.

A view confirms that the item was opened, not that the student read a document, watched an entire video, or understood the material. If another requirement already represents the work students must complete, you do not need to add a separate view requirement.

Submit or Participate

Some activities provide requirements tied to the action students take. For example:

  • An Assignment can require the student to submit before it is complete.
  • A Forum can require a specific number of posts, discussions, or replies.
  • A Quiz can require one or more submitted attempts.

These requirements can mark the activity complete before grading is finished, which is useful when completion should mean that the student did the work.

Receive a Grade or Passing Grade

Receive a grade marks the activity complete once any grade is recorded. It does not require a particular score.

Use Require passing grade when completion should depend on meeting the activity's Grade to pass. Enter the correct passing value in the activity's grade settings and select both the grade and passing-grade requirements.

If the work must be graded manually, such as an assignment or a quiz containing essay questions, completion based on receiving a grade will remain incomplete until the grade is entered.

After Students Begin Working

Students can see the requirements and their completion status on the course page, within the activity or resource, and in the course index. You can review completion for the entire class in the Activity completion report.

Important: Moodle locks the completion settings after at least one person has completed the item. If you unlock and change them, Moodle deletes the existing completion records for that item and recalculates automatic completion where possible. Manual completion cannot be recalculated, so students would need to mark the item complete again.

Set completion requirements before students begin the activity whenever possible. If a change is necessary later, consider how resetting the completion data will affect students and any Restrict access rules that depend on it.
