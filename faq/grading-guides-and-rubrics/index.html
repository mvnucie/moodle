How do I use rubrics and grading guides in Moodle?

Back to Moodle FAQ

Rubrics and grading guides replace the single grade box in a Moodle Assignment with a structured form. Both can make expectations clearer for students and help you grade consistently, but they work differently.

Use a rubric when you want to select one defined achievement level for each criterion. Use a grading guide when you want to enter any score up to a maximum for each criterion and write criterion-specific comments. The process below uses a Moodle Assignment, where these methods are most commonly used. They are also available with Whole forum grading in a Forum.

Choose the Right Grading Method

Use a Rubric for Defined Performance Levels

A rubric presents each criterion as a row with specific achievement levels and point values. While grading, you select one level for every criterion. Moodle adds the selected points and converts the result to the assignment's maximum grade.

A rubric works well when:

  • each criterion has clearly defined levels such as Excellent, Proficient, Developing, and Beginning;
  • you want students to see the complete performance scale before submitting; and
  • you don't need to award a score between two defined levels.

Use a Grading Guide for Flexible Scores

A grading guide lists criteria with a maximum score for each one. While grading, you enter any score from zero through that maximum and can provide a separate comment for each criterion.

A grading guide works well when:

  • you want structured criteria but need flexibility within each point range;
  • criterion-specific written feedback is important; or
  • you use recurring feedback that could be added to a frequently used comments list.

Set the Grading Method

  1. Open the Assignment Settings

    Create a new Assignment or open an existing one and select Settings. Expand the Grade section.

  2. Choose the Method and Maximum Grade

    Set Grading method to Rubric or Grading guide. Confirm that Maximum grade matches the value the assignment should contribute to the Moodle gradebook.

    Important: The point total inside the grading form can differ from the assignment's maximum grade because Moodle converts the form result proportionally. Matching the two totals, when practical, makes the calculation easier to understand.

  3. Save and Open Advanced Grading

    Select Save and display. Moodle may take you directly to the grading-form setup page. If it doesn't, open the Assignment and select Advanced grading from the menu at the top of the page.

  4. Start a New Form or Reuse One

    Select Define new grading form from scratch to build a new form. If you have already created a suitable rubric or grading guide, select Create new grading form from a template. Reusing a form is covered later in this article.

Build the Grading Form

Give the form a clear Name. The name and description help you identify the form later but aren't shown to students. Then complete the editor for the method you selected.

Build a Rubric

  1. Select the criterion text and enter what you are evaluating.
  2. For each level, enter a clear performance description and its point value.
  3. Use Add level or Add criterion as needed. You can also duplicate a criterion and revise the copy.
  4. Review the rubric options. Keep Allow users to preview rubric selected if students should see the rubric before they submit. Allow grader to add text remarks for each criterion is enabled by default and lets you write a separate comment for each criterion while grading.
  5. Select Save rubric and make it ready.

Important: When grading, Moodle permits only the point values represented by the levels you created. If a criterion has levels worth 0, 3, and 5 points, you cannot award 4 points for that criterion.

Build a Grading Guide

  1. Enter a name for each criterion.
  2. Add a description for students so they understand what the criterion measures.
  3. Add a description for graders when internal guidance would help you or another grader apply the criterion consistently.
  4. Enter the maximum score available for the criterion.
  5. Use Add criterion for each additional area you need to assess.
  6. Add frequently used comments if you want reusable feedback available while grading.
  7. Review the guide options to decide whether students may see the guide definition and the points available for each criterion.
  8. Select Save grading guide and make it ready.

A form saved as a draft cannot be used to assess submissions. When the form is complete, make sure its status is Ready for use.

Grade Submissions

Open the Assignment and select Grade. Moodle displays the submission and the active grading form in the grader.

Grade with a Rubric

  1. Select one achievement level for every criterion. Moodle cannot calculate the final grade until every criterion has a level.
  2. If remarks are enabled, enter criterion-specific comments where helpful.
  3. Add overall Feedback comments or feedback files if those feedback types are enabled in the Assignment.
  4. Select Save changes or Save and show next.

Grade with a Grading Guide

  1. Enter a score for each criterion, up to the maximum shown.
  2. Enter a comment for each criterion where feedback is needed. Select a frequently used comment to insert it if you created any.
  3. Add overall Feedback comments or feedback files if those feedback types are enabled in the Assignment.
  4. Select Save changes or Save and show next.

If the form's student-visibility options are enabled, students can review the criteria before submitting and see the completed form with their grade and feedback afterward.

Reuse or Edit a Grading Form

Reuse a Form in Another Assignment

Set the new Assignment to the same Grading method, open the Assignment, and select Advanced grading from the menu at the top of the page. Select Create new grading form from a template. Search for words from the form's name, description, or criteria. Include your own forms in the search results if needed, then use the appropriate form as the template.

Only forms marked Ready for use can be reused. Moodle creates an independent copy for the new Assignment, so later edits to the copy don't change the original form. A grading form is also copied when its Assignment is duplicated or imported into another course.

Edit the Current Form

Open the Assignment and select Advanced grading from the menu at the top of the page. Select Edit the current form definition, make the changes, and save the form so it remains ready for use.

Important: Avoid changing criteria, levels, or point values after grading has begun. Moodle may mark existing assessments as needing review, and you may need to reassess submissions so the grades remain valid and comparable. Correcting a minor wording error may still require you to decide whether existing assessments should be reviewed.
