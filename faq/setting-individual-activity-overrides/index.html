How can I give individual students different dates or settings for an activity?

Back to Moodle FAQ

Use an override in a Moodle Assignment or Quiz to give a student different dates without changing the activity for everyone else. Quiz overrides can also change the time limit or number of attempts. If several students need the same change, use a Group override for a course group.

Add an Override

  1. Open the assignment or quiz

    In your Moodle course, open the Assignment or Quiz you want to adjust. In the activity's toolbar, select More → Overrides.

  2. Choose a student or group

    Select User overrides, then Add user override. Choose the student from the user list. If you've set up groups in your course and want to apply an override to a group, select Group overrides and Add group override instead, then choose the group.

  3. Set the different dates or settings

    Adjust the fields that apply to this student or group, then select Save or Save and enter another override. Review the override in the list after saving. Repeat for students who need different settings.

For Assignments: Set Individual Deadlines

An assignment override can change Allow submissions from, Due date, and Cut-off date. The due date marks a later submission as late; the cut-off date stops submissions. If you extend a student's due date and the assignment has a cut-off date, check that the cut-off also allows the student to submit.

For example, if students complete one assignment on individual schedules, set the assignment's regular due date and add a user override for each student whose deadline differs. Each student will see the date that applies to them in the assignment and their Moodle calendar. Students with the same schedule can share a group override.

For Quizzes: Change Dates, Time, or Attempts

A quiz override can change Open the quiz, Close the quiz, Time limit, and Attempts allowed for one student or group. For example, you can give a student a longer time limit or an additional attempt, or give a group a different testing window.

If a student needs more time during a scheduled quiz, check both the Time limit and Close the quiz setting. A longer time limit doesn't by itself extend the quiz's closing time.

Check activity access: An override doesn't remove separate Restrict access rules or make a hidden activity visible. If the activity has a date restriction, make sure it still allows the student to access the activity during the overridden window. A user override takes precedence over a group override for the same student.
