How can I focus on one student or one assignment in the gradebook?

Back to Moodle FAQ

Use Single view to see one student's grades across the course or students' grades for one assignment. This focused gradebook view makes it easier to review scores, enter grades in bulk, and make individual adjustments when needed.

Choose Where to Grade

Moodle provides two places to enter grades, and the right choice depends on what you're grading:

  • In the activity: Grade Assignment submissions, Forum work, and Quiz answers in the activity itself. This keeps the grade connected to the work, feedback, rubrics, and any grading workflow. Those grades then appear in the gradebook.
  • In the gradebook: Use Grader report or Single view to enter scores for manual grade items, or to make an intentional grade override. A manual grade item is a gradebook entry that isn't connected to a Moodle activity.

Keep manual grade items to a minimum. For a presentation, paper exam, or other work completed outside Moodle, you can use an Assignment with submission types disabled. It still provides instructions, a Due date, and activity-based grading without requiring students to upload anything. A manual grade item doesn't provide an assignment due date.

Single view is especially helpful during a student conference, when reviewing scores for one assessment, or when entering an existing manual item such as a participation score. Reviewing a blank grade can also help you identify something to investigate, but a blank doesn't tell you whether work is missing or just hasn't been graded. Check the activity before deciding.

Review One Student or Grade Item

  1. Open Single view

    Open your course and select Grades from the course navigation. In the gradebook navigation menu, select Single view.

    Grades → Single view

    If you're already in Grader report, you can also open the three-dot menu beside a student's name or a grade item's heading and select Single view for this user or Single view for this item.

  2. Choose the student or grade item

    Under View by, choose one of these options:

    • Users: Search for and select a student to see their grades across the course.
    • Grade items: Open Select a grade item, then search for and select the assignment, quiz, forum, or manual item to see students' grades for that item.

    If a group filter is available, make sure it includes the students you want to review. Moodle can remember your last selection, so check the student or item named in the report heading.

  3. Read the focused report

    Review the Grade, Range, and Feedback columns. Range shows the item's grading scale, so a score of 18 in a 0–20 range means 18 out of 20.

    The Override and Exclude columns show whether those settings apply. You can use the navigation at the bottom to move to another student or item. If there are additional pages, use the page controls or Items per page to see more rows.

Enter or Override Grades

Enter Scores for a Manual Grade Item

Select the manual item under Grade items and turn Edit mode on. Enter each student's score in Grade, add Feedback if needed, and select Save at the bottom. An ordinary manual item doesn't require an Override selection.

Override an Activity Grade Only When Needed

An override stops the activity from updating that gradebook grade. Later grading or regrading in the activity won't replace the overridden score until you remove the override. Correct ordinary grading errors in the activity whenever possible.

Use an override only when the gradebook score needs to differ deliberately from the activity's score, such as a documented adjustment that can't be recorded appropriately in the activity.

  1. Select the student or grade item and turn Edit mode on.
  2. Select Override for only the row you intend to change. This enables its grade and feedback fields.
  1. Enter the replacement Grade within the item's Range. Add a brief explanation in Feedback when appropriate for the student to read.
  2. Select Save, then verify the score and override status. Save before switching students, items, or pages.

Leave calculated category and course totals alone. If a total looks wrong, investigate the underlying grades or gradebook setup instead of overriding the total.

Remove an Override

To return control to the activity, turn Edit mode on, clear Override for that row, and select Save. The activity's grade can replace the manually entered score, so confirm the resulting grade. If it still doesn't match the activity, contact CIE.

Exclude an Excused Item

Exclude removes that grade from the student's grade calculation while retaining the grade entry. Use it when a student is excused from an item under your grading policy. With Edit mode on, select Exclude for the intended row and select Save. Clear it and save to include the grade again.

Bulk Insert Grades

Bulk insert grades applies the same score to multiple entries. It's most useful when everyone affected should receive the same value:

  • A shared score for an existing manual item: Record the same participation credit or other common score for the whole class.
  • Remaining zeros for a manual item: After recording earned scores, fill the remaining empty grades with zero when your policy calls for it and no entries need to remain ungraded.

Bulk insertion replaces scores; it doesn't add points to them. For activity grades, it also creates overrides for the scores it changes. Don't fill blanks with zeros while submissions await grading, students have extensions, or work is excused.

  1. Select one grade item and check the affected students

    Choose Grade items under View by, then select the item. Check any group filter and review the students' scores. Bulk insertion can affect entries beyond the visible page, so use Items per page or review each page before proceeding.

  2. Open Bulk insert grades

    Turn Edit mode on. Save any pending edits first, then select Bulk insert grades from Actions.

    In the dialog, select I understand that my unsaved changes will be lost. to enable the options.

  3. Choose which grades to fill

    • Empty grades: Fill entries that don't have a grade, leaving existing scores unchanged. A recorded zero already counts as a grade.
    • All grades: Replace both existing scores and empty entries with the same value. Choose this only when you intend to replace every affected score.

    Enter the score in Insert new grade. Check the value before saving; the dialog starts with zero.

  4. Save and verify the results

    Select Save in the dialog. This applies the bulk change. Review the resulting scores and any Override indicators before leaving the report.

The Actions menu also includes Override all, Override none, Exclude all, and Exclude none. These change multiple rows' override or exclusion settings. Use the individual row controls for a change that belongs to one student or item.
