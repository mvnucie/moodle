How can I reopen student submissions for an assignment?

Back to Moodle FAQ

To let a student submit revised work while keeping the original submission, an assignment must allow more than one attempt. You can choose to grant additional attempts yourself or have Moodle open them after grading. For a correction to the same submission, Revert the submission to draft is another option when the assignment uses the submit button.

Allow Additional Attempts

  1. Open the Assignment Settings

    Open the assignment in your course, select Settings, and expand Submission settings.

  2. Increase the Allowed Attempts

    Set Allowed attempts to 2 or more, or choose Unlimited. The limit includes the student's first submission, so 2 permits one additional attempt.

    When Allowed attempts is 1, the Grant attempts setting is not available. Once a student reaches the allowed number, Moodle cannot reopen another attempt.

  3. Choose How Moodle Grants Attempts

    Use Grant attempts to select the condition for reopening:

    • Manually: You decide which students receive another attempt, using the Submissions page or grading screen. Best when a student needs an individual opportunity to revise.
    • Automatically: Moodle opens another attempt after you grade a submission, regardless of the grade, until the attempt limit is reached. Useful for assignments designed around repeated feedback and revision.
    • Automatically until pass: Moodle opens another attempt after grading only when the student scores below the passing grade. Set Grade to pass in the assignment's Grade settings so Moodle knows when to stop.

    Select Save and return to course or Save and display when finished.

Reopen an Attempt Manually

If Grant attempts is set to Manually, follow these steps for the student who needs to resubmit:

  1. Open the Submissions Page

    Open the assignment and select Submissions from the assignment navigation.

  2. Allow Another Attempt

    Find the student. In the Status column, open the three-dot submission actions menu and select Allow another attempt.

  3. Have the Student Submit Again

    Moodle opens a new attempt for that student. They can now upload or enter revised work, and their earlier submission and feedback remain available in the attempt history.

Important: Opening a new attempt does not extend the assignment's Cut-off date. If that date has passed, the student will also need an appropriate extension or individual override before they can submit again.

Revert a Submission to Draft

Use Revert the submission to draft when a student submitted the wrong file or needs to correct a submission without creating another attempt. Unlike Allow another attempt, this lets the student change the existing submission. It does not preserve a separate record of the original version.

This option requires Require students click submit button to be set to Yes under Submission settings. That setting lets students work on drafts and then finalize them with Submit assignment. With the setting at No, students do not use that draft-to-final submission process.

  1. Return the Submission to Draft

    Open the assignment's Submissions page. Find the student, open the three-dot menu in the Status column, and select Revert the submission to draft.

  2. Ask the Student to Resubmit

    The student can use Edit submission to correct or replace their work. They must select Submit assignment again when finished. If the cut-off date has passed, address that date as well.

Note: The Require students click submit button setting cannot be changed after students have submitted to the assignment. If it's set to No, you cannot switch it on to use draft status. Instead, allow another attempt using the instructions above.

Grade and Review Multiple Attempts

To grade a revised submission, open the assignment and select Grade, or choose Grade for the student on the Submissions page. The grading interface opens the latest attempt.

To review an earlier version, scroll to the bottom of the grading panel on the right and select View a different attempt. Choose the attempt you want to inspect. This is where you can find the previous submission, grade, and feedback. Return to the latest attempt when you're ready to grade the resubmission.
