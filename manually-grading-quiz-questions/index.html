How do I manually grade questions in a Moodle quiz?

Back to Moodle FAQ

Open the quiz in your course and select Results. Use the report dropdown near the top of the page to choose Manual grading or Manual grading by student.

These views are the most efficient way to grade Essay questions and other responses that require manual grading. You can read responses, enter points, and add feedback without opening each question in each student's attempt separately. Essay responses need your grading even when the expected answer is only a few words. Moodle's Short answer question type, by contrast, is graded automatically against the answers you've configured.

  • Manual grading: Work through one question across students. Use this when grading the whole class so you can apply the same criteria consistently before moving to the next question.
  • Manual grading by student: Work through one student's responses together. Use this to finish a student's exam in one sitting, grade a late submission, or consider responses in the context of that student's other answers.

Grade One Question Across Students

  1. Choose the Question and Responses

    Select Results → Manual grading. The question list shows how many responses are waiting for grading and how many have already been graded.

    In the question's row, choose the link for the responses you want:

    • To grade: Select grade to work only on responses still awaiting a manual grade.
    • Already graded: Select update grades to revise points or comments you've already entered.
    • Total: Select grade all to review all responses to that question, including those already graded.

    If To grade is zero, use one of the other columns to review or change existing grades.

  2. Set Up Your Grading Batch

    Under Options, use Attempts to grade to choose the available grading status. Set Questions per page to the number of responses you want to work through before saving.

    Use Order attempts by to choose an order, such as First name, Last name, or Random. Select Change options before entering grades.

  3. Read, Score, and Comment

    Read each response and review any attached files. Enter the earned score in Points, using the maximum displayed beside the field. For partial credit, enter the actual points earned, such as 1.5 out of 2.00. Enter 0 when no credit is earned.

    Add individual feedback in Comment as needed. If the question includes grader information, use it as a reference while evaluating responses.

  4. Save the Batch and Continue

    At the bottom of the page, select Save and show next. Continue through the remaining batches for this question, then use Back to the list of questions to choose the next question.

    Return to the list when you're finished and check To grade for any responses still awaiting a grade.

Save before leaving the page. Entering points or comments doesn't save them automatically. Use the grading page's save button before changing reports, changing options, or returning to a list.

Grade One Student's Responses Together

  1. Find the Student's Attempt

    Select Results → Manual grading by student. Each row represents a student's quiz attempt. If multiple attempts are allowed, check the Attempt column so you're working on the intended attempt.

    Use grade under To grade for responses awaiting grading, update grades under Already graded to revise manual grades, or grade all under Total to review the attempt's questions together. The grade all view can include automatically graded questions too.

  2. Grade the Selected Responses

    The selected questions for that attempt appear together. Work through them using the same Points and Comment fields described above.

  3. Save and Return to the List

    At the bottom, select Save and go to the list of attempts. Choose another student or confirm that no responses remain under To grade for the attempt you just graded.

Adjust Automatically Graded Questions

You can also use these reports to award partial credit, accept a valid response that wasn't recognized, correct a score, or add individual feedback to an automatically graded question.

  1. Return to the question or student-attempt list and select Also show questions that have been graded automatically.
  2. For a class-wide review of one question, use Manual grading. In that question's row, select update grades under Automatically graded, or grade all under Total to include responses you've already adjusted manually.
  3. For changes to one student's attempt, use Manual grading by student and choose the corresponding link in that student's row.
  4. Change Points and add a Comment where needed, then use the save button for that view.

To add feedback without changing a score, keep the existing Points value. After a response is manually graded, look under Already graded or use grade all if you need to revisit it.

Change Just One Response

If you're already reviewing an individual attempt, you can select Make comment or override points beneath a question. Enter the revised Points or a Comment in the grading window and select Save. This works for both manually and automatically graded questions; the two manual grading reports are faster when you have several responses to work through.
